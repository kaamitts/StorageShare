восемь районов, ошибочный код района и отсутствие доступа без авторизации.
Его можно повторить: `python scripts/api_smoke.py http://localhost:8080`.
Скрипт создаёт отдельный тестовый аккаунт с уникальным email.

## Границы проверки

Docker Engine и PostgreSQL отсутствуют в среде сборки. Образы Docker/Nginx,
healthchecks и полный Compose runtime здесь не запускались. Поэтому перед слиянием
нужно локально выполнить `docker compose up --build -d`, открыть приложение
и повторить smoke-тест с адресом localhost:8080. Проверки SQLite не заменяют проверку
целевой PostgreSQL. Конфигурация предназначена для локальной демонстрации Sprint 1.

Архив содержит исходники, документацию и lockfile; не содержит .git, node_modules,
виртуальное окружение, БД, .env, access/refresh токены или сборочные временные файлы.
