# StorageShare — Sprint 1: QA-отчёт для Jira

Дата фактического прогона: **29 октября 2026**.
Версия: **StorageShare-Sprint1-integrated.zip**; проверены файлы итоговой интеграции.
Среда: React/Vite → Django API → SQLite, Chromium 153, локальный запуск.
Исполнитель проверки: **Codex, браузерная автоматизация и API-тесты**.
Это не заявление о личном ручном прогоне Aldiyar. При добавлении отчёта в его
подзадачи автор проверки и способ исполнения должны оставаться указанными.

## Общие предусловия

- Применены миграции и выполнена seed_storage_points.
- Демо-набор: 3 партнёра, 6 точек; Medeu — 3, Almaly — 2, Bostandyk — 1.
- В Alatau нет демо-точек. Пользователи для регистрации создавались с уникальными email.
- Каждый кейс ниже реально покрыт завершённым браузерным прогоном; API/модельные
  утверждения дополнительно проверялись HTTP smoke-тестом и Django tests.
